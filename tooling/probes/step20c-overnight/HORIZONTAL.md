## Preparation and review

`horizontal_gate.py prepare LAB` compiles only C clients; it creates no socket
and reserves no graphical run. `horizontal_tests.py --output RECEIPT` executes
pure/isolated negative tests. Failed first-pass receipts are preserved separately.
`horizontal_gate.py seal LAB` freezes final fixture/dependency/client/generated
runner/binary/library/source/provenance/test bytes; it cannot create acceptance.

A genuine independent read-only reviewer writes LAB/horizontal/review.json:
status ACCEPTED, independent=true, read_only=true,
scope OVERNIGHT_HORIZONTAL_FINAL_BYTES, blockers=[],
freeze_sha256=SHA256(freeze.json), files=the exact freeze files mapping,
report_file=absolute report path, report_sha256=its exact SHA256.
No historical or synthetic acceptance is valid. Final byte changes invalidate
acceptance. `horizontal_gate.py preflight LAB --case C0` is read only and requires
that review. `run.py LAB C0` then consumes a unique O_EXCL case token before the
run debit; C1/C2 have separate tokens. Existing runs, sockets, bad identity,
changed reviewed bytes and exhausted budgets fail closed. No actual run has been
performed during fixture preparation.

Remaining gates include wider outputs/migration, complete damage/intermediate
frames, atomic generation, static effects/hidden-owner/saved buffers and
ABI/distribution/legal/maintenance. Successful C alone is bounded horizontal
feasibility, never STEP20C production readiness.
